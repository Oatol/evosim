## 批次 14：最短成长期（堵掉「1 格 = 出生即成年」）

用户：「开始！」→ 做我在批次 13 报告里推荐的第一条路。

### 病根（批次 12 / 12.1 / 13 三次实测共同指向）
`growth_plan` 是母体**成熟时的体型**。1 格母体的后代目标就是 1 格，
**出生那一 tick 就"长满了"** → 立刻成年 → 立刻繁殖。3 格目标要花 20~40 tick。
所以「小」不是"更好"，而是**免费**。r 基因型在任何环境里都赢，
富贫斑块造出真实光梯度也没用。

### 做法
```text
芽每 tick：grow_age += 1
长满了  且 grow_age >= growth_min_ticks → 成年
卡够久  且 grow_age >= growth_min_ticks → 提前成熟
```
**两条成熟路径都要过门槛**，否则「长不动就提前成熟」会绕过去。
它是**下限**不是**加时**：3 格身体本来就要长 20~40 tick，所以只惩罚"什么都不用长"的个体。
`LifeCfg::growth_min_ticks` 默认 **20**（只在 `growth_enabled` 打开时生效 → 对旧世界零影响）。
`Organism::grow_age` 新字段，`VERSION` → 18。

### 实测（15000 tick、3 种子、stall=30）
| mingrow | 个体 | 体型 | 最大 | 物种 | 占用 | 嘴% |
|---|---|---|---|---|---|---|
| 0（旧） | 2635 | **1.67** | 4 | 115 | 28.6% | 10.9 |
| 12 | 1698 | 3.12 | 14 | 100 | 34.6% | 11.9 |
| 15 | 1581 | 3.40 | 16 | 87 | 35.1% | 11.7 |
| **20（默认）** | 1125 | **4.92** | 21 | 59 | 32.3% | 42.4 |
| 25 | 962 | 6.38 | 26 | 61 | 35.0% | 39.6 |

6000 tick 单种子能到 **11.58 格**（mingrow=40）。**这是批次 9~13 最强的一次杠杆**
（之前最好 3.32）。

### 富贫斑块终于分化了（关键）
`mingrow=20 + rich=0.7`，按所在格天空光分带：
0–24% 带 4.23 → 25–49% 4.36 → 50–74% 5.94 → 75–99% **8.60**。
**最亮斑块的体型是最暗的两倍。** 批次 13 时这条曲线几乎是平的（1.44 → 1.65）——
因为那时"小"免费，梯度没有东西可筛。

### 代价
人口减半（2635 → 1125）、存活种 115 → 59。但那个 115 里大部分是
"1 格生产者换个细胞类型"的伪多样性；现在最大 21 格、分布宽得多。
想要更多人口/物种就用 15（体型 3.40、物种 87、人口 1581）。

### 教训（写进 DESIGN §9.7.15）
之前所有方案（Kleiber、繁殖折扣、温度、富贫斑块）都在改**成年个体的经济学**，
病根却在**「小」这条路径不收钱**。一旦收钱（哪怕只是时间），体型立刻变成
一条真实的演化轴。

### 踩的坑
- **UI 字符串里的 `"` 必须写成「」**：用 Python 脚本生成 Rust 代码时，
  `\"` 在 Python 非 raw 字符串里会退化成 `"`，把 Rust 字符串提前截断
  （报了 `expected one of )`、`suffixes on string literals are invalid` 这类莫名其妙的错）。
- 改默认值 `growth_min_ticks` 20 之后，5 条成长测试（量的是细胞层面机制、
  依赖"出生即成年"）全部要显式写 `growth_min_ticks = 0`。

176 项测试全绿（app 46 / core 112 / regression 9 / render 3+6 / cli 6），零警告。

## 批次 15：出芽（芽挂在母体上）

用户：「上出芽！」

### 做法
| | 普通繁殖 | 出芽 |
|---|---|---|
| 落点 | 4~6 格外的空地（失败率 70%） | **紧贴母体** |
| 一次性成本 | `food_needed = 细胞数`（随体型涨） | `bud_start_cost`（**固定 1.0**） |
| 同时能生几个 | 1 个 | `floor(n / bud_cells_per_slot)` 个 |
| 未成熟期 | 自己攒能量 | 母体每 tick 喂 `bud_feed`（内部转移，不进热池） |

`Organism::parent_id` 记录母体；成年即清空。`LifeCfg` 加 4 个字段。`VERSION` → 19。

### 三个补丁（全是实测逼出来的）
1. **芽位不能有下限**。第一版 `max(1)`（1 格也有芽位）→ 体型从 4.76 塌到 **1.80**。
   原因同批次 12：出芽最直接的效果是"出生不用找空地"，而"让出生变容易"永远偏向小体型。
2. **没有芽位要退回普通繁殖**。第一版"出芽开着就一律走芽"，`budper >= 4` 时
   小个体直接绝育 → **世界当场全灭（0 个体）**。
3. **芽位门槛必须够大**：每芽位 2/4/6/8 格 → 体型 1.80 / 2.59 / 3.15 / 3.70。

### 第二个关键：母体必须喂得足
`bud_feed = 0.03` 时芽主要靠自己攒，而"自己攒多久"**正比于目标体型** →
大体型的芽长得慢、芽位长期占满，优势被吃光（3.70，仍低于基线）。
`bud_feed = 0.5`（满照收入的 4 倍）→ 芽的成长期被压到「最短成长期」那个**固定值**上，
芽位周转快：0.03→3.70 / 0.10→4.07 / 0.25→4.39 / **0.50→5.57**。

### 实测（15000 tick、3 种子、mingrow=20）
| 配置 | 个体 | 体型 | 最大 | 物种 | 占用 | 异养% | 嘴% |
|---|---|---|---|---|---|---|---|
| 基线 | 1125 | 4.76 | 21 | 59 | 32.3% | 2.1 | 42.4 |
| **出芽** | 1339 | **5.25** | 20 | 64 | **45.1%** | **22.8** | 65.9 |

**每一项都变好了**——第一个不牺牲任何东西就能把生态变厚的机制。
**异养 2.1% → 22.8%** 的机制：芽紧贴母体出生 → 种群从散开的单细胞变成**一簇一簇**
→ 「嘴」第一次有东西可吃。这是「空间结构 → 生态位」的自然涌现。

出芽 + rich=0.7 反而变差（1019 / 5.15 / 33.7% / 18.5%）——富贫斑块把世界整体调暗了。

### 边界（诚实）
出芽仍是繁殖端机制，只把体型 4.76 → 5.25（+10%），不像最短成长期那样翻倍。
真正的超线性需要「后代体型不随母体增长」，但那会破坏遗传（10 格母体生 3 格的芽，
3 格再生 3 格），所以没做。

176 → 182 项测试全绿（app 46 / core 117 / regression 10 / render 3+6 / cli 6），零警告。

## 批次 16：整口咬合（击杀时间 = 血量 ÷ 咬合力）

用户：「让击杀需要按血量算时间，完成后打包可执行文件」。

### 病根
每格 1 HP → n 格 = n 点血（**体积**）；但旧伤害是「每个贴着目标的杀手格各算一次」
（**接触面积**）。20 格猎物被 3~5 格咬住 → 每 tick 挨 3~5 点 → **4~5 tick 就死**。
**击杀时间 ∝ n / 接触格数 ≈ √n**，体型几乎买不到生存时间。

### 做法
```text
咬合力 = 单格伤害 × 这个个体的杀手细胞数
一个个体每 tick 对同一个目标最多造成一次「咬合力」
```
- 不按接触面积叠加（3 个接触格也只咬一口）
- 多只捕食者围攻仍然有效（每只各贡献一份）→「围攻」第一次有意义
- 大捕食者仍更强（杀手细胞多），只是不再"按面积白嫖"

实现：`World.killer_hits: HashSet<u32>`，每次 `act_organism` 开头清空 →
天然 per 攻击者 / per tick。记的是**目标 id**。
`CombatCfg::killer_bite_capped` 默认 **true**；关掉逐位退回旧行为。

### 测试（直接钉住机制，不靠生态数字）
1 格猎物 **1 tick**、5 格 **5 tick**（`kill_time_scales_with_the_victims_health`）；
「3 个接触格仍然只挨 1.0（旧行为 3.0）」；「3 个杀手细胞咬 3.0」；关掉退回旧行为。

### 生态实测
6000 tick 单种子：旧 1452/5.57/杀手 0.0% → 新 1545/5.10/杀手 **0.5%**、异养 26.0→16.4。
15000 tick 3 种子：旧 1339/**5.25**/45.1% → 新 1135/**5.76**/42.4%，异养 22.8→22.5。
**体型 +10%**，人口 -15%。

**坑**：短跑（6000）体型略降、长跑（15000）才翻正 —— **过渡期和稳态的符号可以相反**，
这个项目里反复出现（批次 12 也踩过）。

`VERSION` → 20；186 项测试全绿（app 46 / core 121 / regression 10 / render 3+6 / cli 6）。

## 批次 17：默认值 + 双列参数 + 渲染/画笔修复

用户一次性提了 5 件事：

   代价是起步慢：600 tick 只有 133 只（旧 648），但爬坡健康：

   所以原来 600 行代码**一个字都不用改**，只在中间切一刀、两头各补 `});`。
   窗口 `default_width(680)`、`default_pos([880,42])`。

3. **所有窗口默认关闭**：工具/全局参数/类型参数/检视器/物种/曲线全 `false`。

4. **画布不再重复平铺**：`grid.wgsl` 去掉取模分支，越界一律返回 BACKDROP。
   回环只留在**模拟**里（`grid.index`、光场、生物穿越）。渲染测试

   - `TERRAIN_BRUSH_TYPES` 从 7 项减到 6（去掉 EMPTY）
   - 新增哨兵 `CREATURE_ERASER = 254`，`ERASER = 255` 改名「擦地形」
   - 新增 `World::erase_creature_at(index)`：整只移除、**不撒食物**、能量进热池

## 批次 17.1：修「检视工具点了没反应」

用户报：「检视工具检视生物的时候，检视页面不会出现，可能是默认关的问题」。
—— 猜得完全对。

**根因**：`inspect_at_cursor` 只设了 `panels.selected_org`，从没设 `show_inspector`。
以前 `show_inspector` 默认是 `true`，所以"能用"；批次 17 把它改成默认关，
于是点生物之后窗口根本不画（`Panels::draw` 里是 `if show_inspector { if let Some(id) ... }`）。

**修法**：把这段语义挪进 `Panels::on_inspect(owner)`：
- `owner >= 0` → 设选中 **且** `show_inspector = true`
- `owner < 0`（点空地）→ 清选中、取消跟随，但**不关面板**
- 图钉锁着时不换目标，但仍然保证面板是开的
- 主程序那边先取出 `owner`（借 `world` 的作用域要结束），再调 `on_inspect`

挪进 `Panels` 是为了能单测——`App` 起不来（要窗口/渲染器）。

新增 2 条测试：`inspecting_an_organism_opens_the_panel` /
`pinned_inspector_keeps_its_target_but_stays_open`。

190 项测试全绿（app 50 / core 121 / regression 10 / render 3+6 / cli 6）。
