## 批次 47：体型收益 = 体表面积/体积比（提交 `df6cf23`）

**核心判断**：之前所有"体型收益"都是 `× n^k`，而收入/成本/容量/繁殖门槛
**全部线性于 n**，所以任何 `n^k` 只是改斜率。非线性的量只能来自**几何**。

- `Anatomy::perimeter`（八邻域暴露面数）+ 缓存字段 `perimeter: u16`，
  `add_cell` 增量 `+8 − 2×邻居数`，`recompute` 全量。`VERSION` 36 → 37。
- `svr = 8n / perimeter`，1 格恒 1.00 · 2 格 1.14 · 2×2 1.60 · 3×3 2.25 · 9 格直线 1.80。
- 两个默认关闭的旋钮 `exposure_prod_exp` / `exposure_upkeep_exp`。
  **单格身体两项恒为 1.0**（`single_cell_body_gains_nothing` 钉死）。

**踩的坑**：
1. **必须八邻域**。四邻域下平均 svr = 1.09 而平均体型 3.55 格——3.5 个格子不可能
   只有 9% 的厚度，那是把对角连接当断开了。身体本身是八连通的。
2. **测试里必须关出芽**：9 格身体已有芽位，`reproduce_bud` 固定扣 1.0 启动成本。
   第一版没关，本该产 4.5 实测 3.5，查了半天是这一笔。

**结论**：紧凑度第一次能被推动（`svr≥2` 占比 0.1% → 4.4%，44 倍），
但**平均体型反而略降**（4.81 → 4.58）。奖励抬高的是全世界总收入，
多出来的能量被小体型 r 选择抢走。**第三次**看到这个模式
（批次 11 光合 0.8、批次 47、批次 48）。

## 批次 48：段嵌套（阶段 2，提交 `90bd4da`）

- `MAX_DEPTH = 2`；`emit` 超过深度**不展开**（而不是报错）。
- **`Genome::hash()` 必须递归进 `children`**：阶段 1 只吃了 `children.len()`，
  于是"附肢换了细胞但格数没变"的变异不改指纹 → 两个不同身体算成同一物种。
- `Genome::plan_cells()` 含子段，作为变异预算闸门（必须高估）。
- `segment_op` 5 → 7 个算子（+长子段 / 删子段）；
  **前 5 个算子的目标从"顶层段"改成"任意段"**——否则附肢只能靠生成那一下随机，
  之后再也改不动，是死结构。测试 `child_segments_are_reachable_by_operators` 守着。
- **附肢锚点不能往"下"长**：`(0,1)` 在 `repeat > 1` 时和下一节躯干完全重叠
  被去重吃掉（应 10 格实测 8 格）。改 `(1,0)` 侧向长才对。

**实测（6000 tick / 3 种子 / 收益关闭）**：
平均体型 4.81 → **6.22**，最大 22 → **45**，svr 1.29 → **1.49**，
紧凑% 0.1 → **9.5**，有附肢的成体 0 → **85.4%**，深度 2，
存活种 300.7 → 289.3（-4%），聚类物种 68.3 → 59.3（-13%）。

**体型第一次真的变大，且不需要任何收益机制**——纯粹是形态表达力放开。
代价是物种数小幅下降，属于 K 方向的正常代价。

**收益仍然无效**：k 0 → 1 → 2 时平均体型 6.22 → 5.89 → 4.94，
存活种 289 → 357 → 443。同一个"总量被 r 选择吃掉"的模式。

## 批次 49：细胞器向量（阶段 3 第一刀，提交 `3484481`）

`Organelles { photo, mouth }`（0..=255）挂在 `BodyCell` 和 `GeneCell` 上，
**可遗传**；行为按基因分派，两条轴都 > 0 的格子跑两遍（先光合、再摄食）。

  （`orgmut=0` 的扫描结果与批次 48 完全一致，中间态恒 0.0%）。
- `Flags::PRODUCER`/`MOUTH` 改由基因决定；`hash()` 吃进 org。
- `VERSION` 37 → 38。

**两个必须踩出来的坑**：

1. **成本必须随器官负载缩放**。第一版只让产出乘强度 → `photo=128` 花同样的钱
   只产一半，被选择立刻淘汰（中间态 2.8% 且站不住）。改成 `cost × org.load()`
   （`(photo+mouth)/255`，无器官格子返回 1.0）才对。

   杂食格长不出来。两条轴都进候选之后才出现真杂食格。

**副作用**：组成聚类物种数下降（54.3→40.7），中间态让构成连续化，

## 批次 50：追猎（提交见下）

`chase_prob`（默认 0）：有嘴/杀手、且没贴着猎物时，按概率把移动方向掰向最近的身体。
两档感知——接触（8 邻域，任何有嘴/杀手）/ 视觉（要眼睛，范围 20）。

**第一版要求必须有眼睛 → `chase=0/0.1/0.3/1.0` 结果逐位相同。**
查下去：眼睛 + 移动器 + 嘴/杀手 = **0.0%**；眼睛总数只有 0.7%。
眼睛维持成本 0.030（生产者 3 倍），唯一用处是给大脑加 36 维输入，大脑是随机网络 →
**眼睛在演化里已经死了**。死循环：没眼睛 → 追猎不触发 → 眼睛没价值 → 没眼睛。
所以加"接触"档破环。

**两档之后仍然没有可测效果**（咬合% 38.4 → 37.2 → 35.6，噪声内），
因为作用对象只有 0.2%。

**把行会造出来的三条路**（都是 body_scan 诊断参数，没改默认值）：
- `produce`（移动者能光合）→ 追猎者 0.4%
- `movercost=0.010` → 0.1%
- 两个一起 → **5.0%**（25 倍，行会终于出现）
- 再加 `chase=1.0` → 咬合% 35.2 → 35.7，**仍然噪声内**
- `bite=0.30` → 咬合% 61.0，但追猎者只有 0.3%
- `soil=4/8` → 生态崩（704 / 84 只）

### 结论（重要，别再重复试）

**运动在这个世界里没有独占收益。** 不是感知问题、不是价格问题、也不是收益问题
（咬合 ×5 让咬合占收入 61%，仍然没人会动）。生产者站着不动就能收光，
嘴可以等猎物自己走过来。这解释了批次 23/24/30/43 为什么都没造出"移动者"行会——
它们都在给**已经会动的个体**加收益，而会动的个体不存在。

下一步：给移动一个**独占**资源（只有"换地方"才拿得到的东西）。
地力耗竭最接近，但现在的强度是"惩罚定居"（`soil=4` 就打崩），需要重新标定。

### 三个坑

1. **`think()` 的转身分支必须从 `return` 改成打标记**：原来 `best == out_n-1`
   直接 return，而"大脑想转身"正是"看见猎物但没对准"的那一刻，追猎永远轮不到。
2. **已经贴着就别追**：否则朝猎物走 → 被挡 → 转身 → 绕着猎物打转。
3. **不碰世界 RNG**：`think()` 在 rayon 并行路径上，用 `id + age` 哈希。
