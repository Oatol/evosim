## 批次 47：体型收益 = 体表面积/体积比（提交 `df6cf23`）

**核心判断**：之前所有"体型收益"都是 `× n^k`，而收入/成本/容量/繁殖门槛
**全部线性于 n**，所以任何 `n^k` 只是改斜率。非线性的量只能来自**几何**。

- `Anatomy::perimeter`（八邻域暴露面数）+ 缓存字段 `perimeter: u16`，
  `add_cell` 增量 `+8 − 2×邻居数`，`recompute` 全量。`VERSION` 36 → 37。
- `svr = 8n / perimeter`，1 格恒 1.00 · 2 格 1.14 · 2×2 1.60 · 3×3 2.25 · 9 格直线 1.80。
- 两个默认关闭的旋钮 `exposure_prod_exp` / `exposure_upkeep_exp`。
  **单格身体两项恒为 1.0**（`single_cell_body_gains_nothing` 钉死）。

**踩的坑**：
1. **必须八邻域**。四邻域下平均 svr = 1.09 而平均体型 3.55 格——3.5 个格子不可能
   只有 9% 的厚度，那是把对角连接当断开了。身体本身是八连通的。
2. **测试里必须关出芽**：9 格身体已有芽位，`reproduce_bud` 固定扣 1.0 启动成本。
   第一版没关，本该产 4.5 实测 3.5，查了半天是这一笔。

**结论**：紧凑度第一次能被推动（`svr≥2` 占比 0.1% → 4.4%，44 倍），
但**平均体型反而略降**（4.81 → 4.58）。奖励抬高的是全世界总收入，
多出来的能量被小体型 r 选择抢走。**第三次**看到这个模式
（批次 11 光合 0.8、批次 47、批次 48）。

## 批次 48：段嵌套（阶段 2，提交 `90bd4da`）

- `MAX_DEPTH = 2`；`emit` 超过深度**不展开**（而不是报错）。
- **`Genome::hash()` 必须递归进 `children`**：阶段 1 只吃了 `children.len()`，
  于是"附肢换了细胞但格数没变"的变异不改指纹 → 两个不同身体算成同一物种。
- `Genome::plan_cells()` 含子段，作为变异预算闸门（必须高估）。
- `segment_op` 5 → 7 个算子（+长子段 / 删子段）；
  **前 5 个算子的目标从"顶层段"改成"任意段"**——否则附肢只能靠生成那一下随机，
  之后再也改不动，是死结构。测试 `child_segments_are_reachable_by_operators` 守着。
- **附肢锚点不能往"下"长**：`(0,1)` 在 `repeat > 1` 时和下一节躯干完全重叠
  被去重吃掉（应 10 格实测 8 格）。改 `(1,0)` 侧向长才对。

**实测（6000 tick / 3 种子 / 收益关闭）**：
平均体型 4.81 → **6.22**，最大 22 → **45**，svr 1.29 → **1.49**，
紧凑% 0.1 → **9.5**，有附肢的成体 0 → **85.4%**，深度 2，
存活种 300.7 → 289.3（-4%），聚类物种 68.3 → 59.3（-13%）。

**体型第一次真的变大，且不需要任何收益机制**——纯粹是形态表达力放开。
代价是物种数小幅下降，属于 K 方向的正常代价。

**收益仍然无效**：k 0 → 1 → 2 时平均体型 6.22 → 5.89 → 4.94，
存活种 289 → 357 → 443。同一个"总量被 r 选择吃掉"的模式。
